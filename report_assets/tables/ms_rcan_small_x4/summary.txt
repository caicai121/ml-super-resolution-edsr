MS-RCAN-small Experiment Summary
================================

Model: MS-RCAN-small (Multi-Scale RCAB + RCAN-small framework)
Difference from RCAN-small: RCAB replaced with MSRCAB (1x1+3x3+5x5 branches)
Refine module: NOT added
Edge Loss: NOT added

Training Settings:
- Dataset: UC Merced selected (5 classes)
- Train/Val/Test: 560/70/70
- Epochs: 50
- Batch size: 8
- LR: 1e-4
- Loss: L1
- Best selection: val Y+crop PSNR

Results:
- Parameters: 3,347,839 (RCAN-small: 1,563,199)
- Best epoch: 49
- Best val Y+crop PSNR: 30.19 dB
- Test RGB PSNR: 29.06 dB
- Test RGB SSIM: 0.7747
- Test Y+crop PSNR: 30.67 dB
- Test Y+crop SSIM: 0.8076

Comparison:
- vs Bicubic x4 (+0.92 dB)
- vs RCAN-small (+0.07 dB)
- vs RCAN-pretrained (-1.85 dB)

Conclusion:
Multi-scale RCAB is effective but gain is small (+0.07 dB).
Parameter count doubled (+114%).
Next step: add Refine module on top of MS-RCAN-small.
